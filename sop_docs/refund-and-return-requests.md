# Refund and Return Requests

## Purpose

This company-wide procedure sets the requirements for handling customer return and refund requests. The Customer Service team owns the process.

## Definitions

**Return window** — The period in which a customer may return an eligible item, measured from delivery.

**Reason code** — The required classification recorded for each refund or return request.

**Livestream-only price** — A price available only for an item bought during a livestream.

**Fresh Grocery spoilage claim process** — The process for claims involving perishable food that arrived spoiled.

## Procedure

1. Check the item and request.
   a. Confirm the delivery date and whether the item is within the 30-day return window. Customers can return an item within 30 days of delivery.
   b. Perishable food cannot be returned unless it arrived spoiled. For a spoiled item, follow the Fresh Grocery spoilage claim process.
   c. Record a reason code for every request. Use one of these codes: wrong item, damaged, changed mind or quality issue.

2. Review the request and determine the refund amount.
   a. For an item bought at a livestream-only price, calculate the refund using the price the customer paid, not the list price.
   b. If the refund is above $500, obtain sign-off from a Customer Service team lead before issuing it.

3. Process the return and refund.
   a. Provide the customer with the applicable return instructions and track the returned item.
   b. Issue the refund within 5 business days after the returned item is received.
   c. Record the outcome and any required approval in the order record.

4. Direct livestream questions to the order page.
   a. Hosts and moderators must never promise a refund in the live chat.
   b. Hosts and moderators must point the customer to the order page to submit or follow up on a request.

## Notes

The return window and refund timing are separate requirements. Do not treat a request as approved until it has been reviewed under this procedure. For cases involving spoiled perishable food, use the Fresh Grocery spoilage claim process rather than the standard return process.
