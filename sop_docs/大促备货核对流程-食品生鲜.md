# 大促备货与库存核对流程(食品生鲜运营)

## 适用场景

食品生鲜类目大促(618/双11/周年庆等)前的备货核对,生鲜类目对时效和库存准确性要求高于其他类目。

## 处理步骤

1. **需求预测**:参考历史同类型 campaign 的 GMV/DAU,结合本次预告曝光量,估算预期销量。
2. **供应商产能确认**:提前 7 天跟供应商确认产能是否覆盖预测销量,生鲜类要额外确认冷链运力。
3. **保质期核查**:活动期间在架商品的保质期是否覆盖到活动结束后至少 3 天(避免临期投诉)。
4. **库存系统同步**:预留库存在系统里锁定,避免其他渠道超卖导致直播间拍下无货。
5. **仓储与冷链准备**:生鲜类目额外确认冷库容量、发货时效是否能匹配大促期间的爆发订单量。
6. **异常商品下架预案**:活动开始后如发现某 SKU 库存异常(远超或远低于预期),谁负责紧急下架/补货,响应时限是多少。
7. **活动结束后盘点**:核对实际出库量与系统库存记录是否一致,差异较大要排查原因(参考直播复盘流程)。

## 协同部门

- **供应商对接组**:产能与冷链确认
- **仓储物流**:库存锁定与发货时效
- **风控组**:食品资质合规确认
