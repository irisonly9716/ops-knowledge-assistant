# 风控问题处理流程

## 适用场景

直播间/账号收到平台风控提示(限流、封禁、功能受限、被判定异常订单等),或者投诉导致订单被风控拦截。所有部门通用。

## 处理步骤

1. **确认命中的规则和账号**:登录风控后台,查看具体触发的规则编号、触发时间、涉及的直播场次或商品。截图保存证据。
2. **判断是否本人操作问题**:检查是否有违规话术、虚假宣传、刷单嫌疑等自身原因。如果是,先自查整改,再走申诉。
3. **收集申诉材料**:直播回放片段(问题时间点前后各 5 分钟)、商品资质、物流单据等,越具体申诉通过率越高。
4. **提交申诉工单**:在风控后台提交工单,附上第 3 步的材料,注明账号 ID、场次 ID、诉求。
5. **同步风控对接人**:工单提交后,在风控组值班群 @ 对接人,说明紧急程度(是否影响当天直播)。
6. **等待复核结果**:一般 1-3 个工作日。期间不要重复提交同一工单,会拖慢排队。
7. **结果跟进**:
   - 申诉通过:核对功能是否完全恢复,截图存档,案例归档到本部门知识库。
   - 申诉驳回:找风控对接人要具体驳回原因,判断是否需要升级到风控组负责人。

## 协同部门

- **风控组**:第一联系人,处理申诉审核
- **法务**(涉及资质类问题时):协助准备合规材料
- **技术组**(账号功能异常但风控后台无记录时):排查是否是系统 bug 而非真实风控
