# SOP documents

The SOPs of the evaluation corpus, in Markdown. The Kafka consumer reads, parses, chunks and embeds them;
they end up in `documents` (`doc_type='sop'`) + `doc_chunks` (see `docs/data-schema.md`).

`documents` also holds `campaign_plan` and `campaign_review` documents, which belong to a
specific campaign. Those live in [campaign_docs/](../campaign_docs/); this folder is only for
`doc_type='sop'`.

Five SOPs were written by hand. The other 25 were generated by `llm-service/scripts/generate_corpus.py`
from the briefs in `llm-service/scripts/corpus_spec.py`, and they are committed because a model writes
different text every time. An SOP may contain only the numbers of its brief, so every fact a question can
ask about is known in advance. `uv run python -m scripts.ingest_corpus` uploads them all through the API.

## Format

Each document starts with a frontmatter block (between `---` lines) that maps to `documents` columns:

```markdown
---
title: Document title
department: Department name (must match departments.name exactly) or ALL (every department)
category: Category, e.g. Trust & Safety / Launch checklist / Review
responsible_team: Owning team
---

Body...
```

Department values in use: `Beauty` / `Consumer Electronics` / `Fresh Grocery` / `Home Goods` /
`ALL`. The first four come from `DEPARTMENTS` in `llm-service/scripts/generate_mock_data.py`;
both sides must match exactly, or permission filtering silently finds nothing.

## What makes retrieval hard on purpose

- **The same SOP in every department.** Post-Livestream Review Process, Sale Event Inventory Check and
  Host Onboarding and Review exist once per department, on the same company template, with different rules:
  Beauty reviews within 48 hours, Fresh Grocery the next morning by 10 am, Home Goods once a week.
- **One checklist for two years.** The Black Friday Readiness Checklist exists for 2025 and for 2026, with
  different dates.
- **A rule and its exception.** Prices lock 24 hours before a stream (Promotional Pricing and Discount
  Approval), but 48 hours before a Black Friday 2026 stream.
- **Different authors.** Real documents aren't one template filled in: some people write fragments, some long
  paragraphs, some an FAQ. So each generated SOP has one of five ways of writing (standard, like the
  hand-written ones; terse; explainer; formal; faq), and each department has two people who write most of its
  SOPs. Paragraphs across the corpus run from 1 word to 165, with a median of 25.
