# 主播签约与考核流程(3C 数码运营)

## 适用场景

3C 数码运营部门新签约主播,或存量主播季度考核。

## 处理步骤

1. **背景审核**:核实主播过往带货类目、粉丝画像是否与 3C 数码受众匹配,查历史违规记录。
2. **试播考察**:安排 1-2 场试播(非独立开播,搭配成熟主播),观察对产品参数的熟悉度、临场应变。
3. **合同条款确认**:坑位费/佣金比例、最低场次要求、考核周期,法务过一遍合同模板。
4. **产品知识培训**:数码类目专业性要求高,安排至少 4 小时的产品培训 + 笔试,不通过不能独立开播。
5. **首月保护期**:前 4 场由资深运营陪场,复盘每场数据,发现问题及时纠正。
6. **季度考核**:GMV、转化率、退货率、投诉率四项指标,对比部门平均水平,低于阈值触发"约谈 -> 观察期 -> 解约"三级处理。
7. **考核结果归档**:考核表存入主播档案,作为下次排期优先级的参考依据。

## 协同部门

- **法务**:合同审核
- **风控组**:历史违规记录核查
- **数据组**:季度考核数据出具
