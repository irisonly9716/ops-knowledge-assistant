# 美妆新品首发 复盘报告

## 整体结果 vs 预期

| 指标 | 预期(见策划案) | 实际 | 结论 |
|---|---|---|---|
| GMV | 180-220 万 | 237.2 万 | 超预期 |
| 转化率 | 7%-9% | 8.05% | 符合预期 |
| 在线人数峰值 | 1.2-1.5 万 | 1.85 万 | 超预期 |

## ROI 测算

**ROI 不是 (GMV - 成本) / 成本这么简单**——成本要拆成两部分:**运营成本**(主播坑位费 +
推广投放 + 赠品,不随商品变化)和**商品成本**(每款商品的成本价 × 销量,汇总自
`campaign_products` 表,不是我们估的,是商品表自带的字段)。

- 运营成本:35 万元(坑位费 + 推广 + 赠品,人工估算,没有单独的结构化字段记录)
- 商品成本:137.5 万元(四款主推品的 `cost_price × units_sold` 汇总,来自商品表)
- 总成本 = 35 + 137.5 = 172.5 万元
- 净利润 = GMV - 运营成本 - 商品成本 = 237.2 - 35 - 137.5 = 64.7 万元
- **ROI = 净利润 / 总成本 ≈ 64.7 / 172.5 ≈ 37.5%**

这次修正了之前一版复盘里的算法错误——之前把"成本"当一个笼统的数字,只扣了运营成本,
没扣商品成本,算出来的 ROI 虚高了一大截。**商品成本这类干净的数字现在直接从
`campaign_products` 表拿**,不用在复盘文档里手动估算;这篇文档里唯一还需要人工填的,
只有"运营成本"——因为项目目前没有单独记录坑位费/推广费的结构化字段。

## 商品维度复盘

| 商品 | 销量 | 成本价 | 销售额 | 利润 | 利润率 |
|---|---|---|---|---|---|
| 防晒霜 | 4987 | 132.90 | 132.5 万 | 66.3 万 | 50.00% |
| 眼影盘 | 3398 | 144.34 | 81.2 万 | 32.2 万 | 39.63% |
| 面膜 | 3260 | 39.71 | 21.1 万 | 8.2 万 | 38.74% |
| 洗面奶 | 2750 | 33.51 | 15.3 万 | 6.1 万 | 39.64% |

(这四款是本场主推品,销售额口径跟 `campaign_metrics.gmv` 不完全对应——GMV 是整场
活动全量商品的每日汇总,这里只挑了主推品做重点复盘,不代表 GMV 的全部构成。)

**几个发现**:

1. **防晒霜利润率明显高于其他三款(50%)**,而且销量也是全场最高,是这场活动实际
   贡献利润最多的单品——策划案里没有把防晒霜列为主推款,这次复盘发现它值得在
   下次同类活动里提前规划成主推款,而不是顺带卖
2. **面膜/洗面奶利润率接近(38%-40%)但销售额偏低**,更适合当搭配款而不是主推款,
   跟它们在策划案里的定位基本一致
3. 眼影盘售出表现稳定,利润率 39.63%,是这场活动第二大利润来源

## 给下一场类似活动的建议

- 防晒霜这类"高利润率 + 高销量"的品,应该提前识别出来重点排期,不要等复盘才发现
- 运营成本(坑位费/推广费)目前没有结构化记录,后续如果想让 ROI 计算不用人工估算,
  需要在 campaign 或活动预算层面补一张成本记录表
