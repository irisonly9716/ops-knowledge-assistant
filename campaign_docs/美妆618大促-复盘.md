# 美妆618大促 复盘报告

## 整体结果 vs 预期

| 指标 | 预期(见策划案) | 实际 | 结论 |
|---|---|---|---|
| GMV | 80-120 万 | 107.8 万 | 符合预期 |
| 转化率 | 6%-8% | 7.24% | 符合预期 |
| 在线人数峰值 | 1-1.3 万 | 1.23 万 | 符合预期 |
| 运营成本 | 计划 14.8 万 | 实际 18.2 万 | **超预算 23%**,大促期间广告位竞价上涨,命中了策划案里的风险点 |

## ROI 测算(这版改过公式,记录一下为什么)

**之前两版都算错了**:第一版只扣了运营成本、没扣商品成本,ROI 虚高;第二版把商品成本
也算进了分母,但这是错的——**商品成本已经在 `campaign_products.profit` 里扣过了**(利润 =
销售额 - 商品成本,这个钱本来就是顾客买单付的,不是公司这场活动"额外投入"的钱)。
真正该问的问题是:**这场活动的营销投入(运营成本),换来了多少利润?**

- 商品总利润(6 款主推品的 `profit` 汇总,来自 `campaign_products` 表,已经扣过商品成本):**46.3 万元**
- 实际运营成本(`campaigns.actual_operating_cost`):**18.2 万元**
- **ROI = 商品总利润 / 运营成本 = 46.3 / 18.2 ≈ 2.55**,即每投入 1 元营销成本,换回约 2.55 元的商品利润

这两个数字现在都是结构化字段查出来的(`SUM(campaign_products.profit)` +
`campaigns.actual_operating_cost`),复盘文档里不需要再手动估算或临时拼公式。

## 商品维度复盘

| 商品 | 销量 | 成本价 | 销售额 | 利润 | 利润率 |
|---|---|---|---|---|---|
| 防晒霜 | 1323 | 85.35 | 27.0 万 | 15.7 万 | 58.19% |
| 面膜 | 4548 | 21.83 | 19.9 万 | 9.9 万 | 49.99% |
| 精华液 | 1889 | 47.70 | 17.7 万 | 8.7 万 | 49.11% |
| 口红 | 535 | 152.20 | 12.8 万 | 4.6 万 | 36.33% |
| 粉底液 | 319 | 107.96 | 8.0 万 | 4.6 万 | 57.19% |
| 眼影盘 | 246 | 143.86 | 6.2 万 | 2.7 万 | 43.37% |

**几个发现**:

1. **防晒霜利润率最高(58.19%)且销量也不错**,策划案把它定位成"引流款",实际
   它同时也是利润率最高的单品——大促期间防晒这类刚需品,让利力度不用给太狠也能走量
2. **口红销量全场最低(535 件)**,策划案里提前标注的风险("彩妆类目竞品促销力度大,
   凑单效果可能打折扣")命中了——彩妆三件套里口红表现明显弱于粉底液/眼影盘
3. **运营成本超预算 23%**,策划案的风险点也提前警示过("大促期间广告位竞价通常上涨")——
   这类预算超支在大促场次里似乎是规律性的,下次大促类活动的预算应该提前多留 20%+ 缓冲

## 给下一场类似活动的建议

- 大促类活动的运营成本预算,建议按历史"实际超计划幅度"(这次是 23%)留出缓冲,
  不要直接按平时活动的比例估算
- 彩妆凑单款在大促期间竞争激烈,选品时可以考虑差异化(避开跟头部大促同款竞品正面竞价)
